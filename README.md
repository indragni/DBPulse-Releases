# dB Pulse desktop downloads

This repository hosts the official binary releases of **dB Pulse: Decibel Meter** from Indragni Solutions. The app is free and has no ads.

- Website: https://livedecibelmeter.com/
- Privacy: https://livedecibelmeter.com/privacy/
- Help: hello@livedecibelmeter.com

Linux downloads are provided as `.deb` and AppImage. The Snap Store and Flathub listings, when available, manage their own updates. The direct AppImage checks this repository for signed updates.

Microphone readings are estimates until calibrated against a suitable reference meter. The app is not a certified sound level meter or safety determination.
